2. Set Up a GitHub Repository
Create a GitHub Account: If you don’t already have one, sign up on GitHub.

Create a New Repository:

Go to your GitHub profile.
Click the green New button (next to Repositories).
Enter a repository name (e.g., EEG_Analysis_Functions).
Add a description of the project.
Choose the repository type (public for open access).
Optionally, initialize the repository with a README.md file and a license (e.g., MIT License).
3. Upload Your Code
Option A: Direct Upload via Browser
Open the repository on GitHub.
Click the Add File > Upload Files button.
Drag and drop your folder or individual files into the browser window.
Add a commit message (e.g., "Initial upload of EEG analysis functions").
Click Commit Changes.

Install Git: If not already installed, download and install Git.
